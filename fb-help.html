Help

First line

Your first line should start with the student's name. If the student's first name has a space in it, replace the space with an underscore (_). For example, Sarah Jane would be written as Sarah_Jane. The end of the line can be the attempt number. This is optional, but attempts after 1 have custom text. Between the start and end, you can put anything. I like to put the name of the assessment as a reminder.

For example, if Ashley is completing her third attempt at mathematics assessment C, the first line could be:

Ashley maths C 3

Important: any number at the end will be read as the attempt number, so, for example, if you want to write about assessment 2, add a fullstop to the end, e.g:

Jimmy physics 2.

Remaining lines

Each remaining line will be interpreted as something to change. If the line starts with Q, it will be called a question. If not, it will be called a thing.

Here is an example of questions:

Gwen maths B
Q2 - B
Q11 - not answered

Here is an example of things:

Linda PREASU 1000 word document
Use double spacing
Please use the correct APA formatting for references.

If no questions or things are listed, the format button will create a message saying the student's attempt is satisfactory.

Buttons

🖊️Format

Format will put the text into the right format and copy it to your clipboard.

➕Copy Qs

This button does not show up in document mode. Copy Qs will copy just the questions to your clipboard.

📎LMS Format

This button only shows up in document mode. LMS format will do the same as format, but it will adjust the wording to make sense on an LMS.

🔰SNQ

SNQ will create the response needed for the Student Needs Questionnaire and copy it to your clipboard.

Type

The type dropdown has 3 options: Auto, Questions and Things. Questions will phrase the response in terms of questions, Things will phrase the response in terms of things and Auto will choose the phrasing based on the text written.

🔄Mode

Mode will switch the colour palette of the website. There are three modes.

📙Help

Help will open this page.

⚙️

The gear button will toggle whether the tickboxes appear.

Tickboxes

Date

Date will include the date after the assessor's name.

Document

Document will adjust the format and text to be appropriate for assessments submitted as documents (i.e. most assessments outside of Northam).

Count Qs

Count Qs will use the number of uppercase Qs as the number of questions. If not selected, the number of questions will be calculated based on the number of lines after the first.

Highlight

Highlight will make any text between double apostrophes ('') become highlighted once formatted. If not selected, the text between double apostrophes will be formatted as bold.

PA

PA being selected will enable passive aggressive mode. This removes the phrases "good job" and "well done" from formatted text.
