Help

First line

Your first line should start with the student's name. If the student's first name has a space in it, replace the space with an underscore (_). For example, Sarah Jane would be written as Sarah_Jane. The end of the line can be the attempt number. This is optional, but attempts after 1 have custom text. Between the start and end, you can put anything. I like to put the name of the assessment as a reminder.

For example, if Ashley is completing her third attempt at mathematics assessment C, the first line could be:

Ashley maths C 3

Important: any number at the end will be read as the attempt number, so, for example, if you want to write about assessment 2, add a fullstop to the end, e.g:

Jimmy physics 2.

Remaining lines

Each remaining line will be interpreted as something to change. If the line starts with Q, it will be called a question. If not, it will be called a thing.

Here is an example of questions:

Gwen maths B
Q2 - B
Q11 - not answered

Here is an example of things:

Linda PREASU 1000 word document
Use double spacing
Please use the correct APA formatting for references.

Buttons

Format

Format will put the text into the right format and copy it to your clipboard.

Copy questions

This button does not show up in document mode. Copy questions will copy just the questions to your clipboard.

LMS Format

This button only shows up in document mode. LMS format will do the same as format, but it will adjust the wording to make sense on an LMS.

Switch mode

Switch mode will switch the colour palette of the website. There are three modes.

Help

Help will open this page.

Tickboxes

Include date

Include date will include the date after the assessor's name.

Document mode

Document mode will adjust the format and text to be appropriate for assessments submitted as documents (i.e. most assessments outside of Northam).
